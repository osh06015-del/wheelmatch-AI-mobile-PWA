# 규정 출처

이 앱의 판정 규칙과 안내 문구가 어디에서 왔는지 기록한다.

**원칙:** 관할 국가 · 출처 URL · 문서 버전(조항) · 시행일을 함께 적는다.
확인하지 못한 항목은 `미확인`으로 남긴다. **지어내지 않는다.**
(규칙 근거: `.claude/rules/safety-critical.md` 6번)

갱신 2026-09-04.

## 1. 핵심 판정 규칙의 근거

### 산업안전보건기준에 관한 규칙 제122조 (연삭숫돌의 덮개 등)

| 항목      | 값                                                                                                                            |
| --------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 관할      | 대한민국 (KR)                                                                                                                 |
| 종류      | 고용노동부령                                                                                                                  |
| 조항      | 제122조                                                                                                                       |
| 시행일    | **미확인** — 국가법령정보센터에서 현행 시행일을 확인할 것                                                                     |
| 확인 방법 | <https://www.law.go.kr> 에서 "산업안전보건기준에 관한 규칙" 검색 → 제122조                                                    |
| 참고 URL  | <https://www.nhis.or.kr/lm/lmxsrv/law/joHistoryContent.do?SEQ=821&SEQ_CONTENTS=3159481&DATE_START=20221018&DATE_END=20210528> |
| 원문 확인 | 조문 요지만 확인. **전문 대조는 아직 하지 않았다**                                                                            |

이 앱이 구현한 항.

| 항  | 요지                                        | 앱에서                                      |
| --- | ------------------------------------------- | ------------------------------------------- |
| ①   | 지름 5cm 이상 연삭숫돌에 덮개 설치          | 체크리스트 `방호덮개 장착`                  |
| ②   | 작업 시작 전 1분, 숫돌 교체 후 3분 시험운전 | **아직 앱에 없다** (`docs/roadmap.md` 참고) |
| ③   | 시운전용 숫돌은 작업 전 결함 확인           | 체크리스트 `숫돌 손상 없음`                 |
| ④   | **최고사용회전속도 초과 사용 금지**         | **`checkRpmSafety()` — 이 앱의 핵심 규칙**  |
| ⑤   | 측면 사용 목적이 아닌 숫돌의 측면 사용 금지 | `checkWorkPurpose()` + 작업별 위험사항      |

**④항이 이 앱이 존재하는 이유다.** 코드에 인용할 때는 조항 번호만 적고
상세는 이 문서를 가리킨다.

## 2. 참고한 지침·표준

| 문서                                                   | 관할 | 버전       | 시행일 | 상태                            |
| ------------------------------------------------------ | ---- | ---------- | ------ | ------------------------------- |
| KOSHA Guide 「휴대형 연삭기 안전작업에 관한 기술지침」 | KR   | M-189-2015 | 2015   | **원문 미확인.** 제목만 확인    |
| OSHA 29 CFR 1926.303 (Abrasive wheels and tools)       | US   | —          | 미확인 | 조문 요지 확인                  |
| OSHA 29 CFR 1910.215 (Abrasive wheel machinery)        | US   | —          | 미확인 | 조문 요지 확인                  |
| HSE HSG17 Safety in the use of abrasive wheels         | UK   | HSG17      | 미확인 | **원문 미확인**                 |
| KS / EN 12413 (안전 상한 80 m/s 근거)                  | —    | —          | 미확인 | **원문 미확인. 코드에 안 넣음** |

OSHA 1926.303은 이렇게 적는다 — 기계의 축 회전속도가 _"maximum operating speed
marked on the wheel"_ 을 넘지 않는지 **장착 전에** 확인할 것. 제122조 ④항과 같은
요구다. 영어 UI의 `rule.rpmSafety`를 `Max operating speed`로 쓴 근거다.

- <https://www.osha.gov/laws-regs/regulations/standardnumber/1926/1926.303>
- <https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.215>
- <https://www.hse.gov.uk/pubns/books/hsg17.htm>

### 80 m/s를 코드에 넣지 않은 이유

`engine.ts`의 원주속도 검증이 쓰는 **15~110 m/s는 안전 한계가 아니다.**
OCR 자릿수 오독을 거르는 상식 범위일 뿐이며, 주석에도 그렇게 적혀 있다.

진짜 안전 상한을 규칙으로 만들려면 KS/EN 12413 원문 확인이 먼저다.
**확인 전까지 이 숫자를 안전 기준으로 인용하지 않는다.**

## 3. 제조사 자료 (규정 아님)

법령이 아니라 제조사 안내다. 용어와 현장 관행을 맞추는 데 참고했다.

| 자료                                  | 확인한 것                                                                                                                  |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 보쉬 코리아 그라인더 안전캠페인 (GWS) | 회전속도 일치 · **내경(보어)이 스핀들과 일치** · 최대 직경 · 덮개 · 측면 손잡이 · 신규 휠 시운전 · 절단 디스크로 연마 금지 |

<https://www.bosch-pt.co.kr/kr/media/service_relaunch_1/campaigns/bosch_safety_campaign/safety_campaign_2_gws.pdf>

내경(H)은 이제 읽는다. 다만 **판정에는 쓰지 않는다** — 이유는 §5에 있다.

## 4. 다국어 용어의 근거

번역 용어를 각 언어권 산업안전 자료와 대조했다. 대조표와 남은 검수 질문은
[i18n.md](i18n.md)에 있다.

| 언어 | 기준으로 삼은 것                                        |
| ---- | ------------------------------------------------------- |
| ko   | 산업안전보건기준에 관한 규칙, KOSHA                     |
| en   | OSHA 1926.303 / 1910.215 표기                           |
| vi   | 베트남 산업안전 교육자료, 보쉬 베트남 자료              |
| id   | 인도네시아 K3 안전자료                                  |
| zh   | 중국어권 산업안전 자료, 홍콩 직업안전건강국 각마기 자료 |

**KOSHA가 외국인노동자용 안전보건자료를 17개 언어로 배포한다.** 검수 기준을
이것으로 삼는다. 작업자가 이미 그 용어로 교육받았기 때문이다.

## 5. 판독 계층 검사의 근거 (2026-09-04 추가)

이번에 추가한 두 검사의 성격을 구분해 적는다. **하나는 규정이 아니다.**

### 표기 일치 — 규정 아님, 데이터 무결성

라벨의 rpm 표기와 m/s 표기가 서로 맞는지 본다. 어긋나면 판정불가로 막는다.

이것은 **법령이나 표준에서 온 규칙이 아니다.** 같은 물리량을 두 단위로 적은
것이므로 환산이 맞아야 한다는, 산술에서 오는 요구다. 허용 폭 10%도 안전
여유가 아니라 **라벨 반올림을 흡수하는 폭**이다 (Φ125 12,200rpm = 79.85m/s,
라벨에는 "80m/s" — 0.2% 차이).

논문·발표에서 이것을 안전 기준으로 인용하지 않는다.

| 항목 | 값            |
| ---- | ------------- |
| 관할 | 해당 없음     |
| 출처 | 없음 (산술)   |
| 성격 | OCR 오독 탐지 |

### 장착 규격(내경) — 제조사 안내, 판정에 쓰지 않음

라벨의 내경(D×T×H의 H)을 읽어 보여준다. **판정하지 않는다.**

근거는 제조사 안내다. 보쉬 코리아 앵글그라인더 안전자료는
_"교체용 휠의 내경이 기계의 스핀들 사이즈와 정확히 맞아야 하며, 맞지 않는
부품은 사용하면 안 됩니다"_ 라고 적는다 (§3 참고).

그런데 **그라인더 명판에는 스핀들 규격이 인쇄되지 않는다.** 대조할 상대가
없으므로 이 앱은 판정할 수 없다. 통용 규격(앵글그라인더 22.23mm 등)을
기준으로 삼으면 그것은 규격 대조가 아니라 **관행 추정**이다. 그래서 값을
보여주고 사용자가 직접 확인하게 한다.

| 항목    | 값                                         |
| ------- | ------------------------------------------ |
| 관할    | 해당 없음 (제조사 안내)                    |
| 출처    | 보쉬 코리아 그라인더 안전캠페인 — §3의 URL |
| 버전    | 미확인                                     |
| 시행일  | 해당 없음                                  |
| 앱 처리 | **경고만.** 판정을 끌어내리지 않는다       |

**제조사별 표기 의미를 추측하지 않는다.** 라벨에 세 값이 D×T×H 순으로
찍힌다는 것 외에는 가정하지 않는다. 순서를 확정할 수 없으면 null로 둔다.

## 6. 이 문서를 고칠 때

1. **표에 넣기 전에 원문을 연다.** 검색 결과 요약만 보고 적지 않는다.
2. 확인하지 못한 칸은 `미확인`으로 둔다. 빈칸으로 두면 확인한 것처럼 보인다.
3. 코드에 조항을 인용했으면 여기에도 추가한다. 한쪽만 있으면 개정 때 놓친다.
4. 법령은 개정된다. 발표 전에 **시행일을 다시 확인**한다.
